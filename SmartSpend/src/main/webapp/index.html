SmartSpend

Personal Expense & Budget Management System

Welcome to SmartSpend, a complete web-based personal finance and budget management solution engineered with Java Servlets, JDBC, MySQL, HTML5, CSS3, Vanilla JavaScript, and Chart.js following MVC architecture.

  • 🔒 User Authentication & Isolation: Secure SHA-256 password hashing & session management.
  • 📊 Interactive Dashboard: Real-time Chart.js circular pie chart of category-wise spending.
  • 💸 Expense Tracking: Add, edit, delete, search, and multi-filter daily expenses.
  • 🎯 Budget Control: Set monthly limits with 4-tier visual alerts (Normal, Warning, Critical, Exceeded).
  • 📈 Monthly Reports: Aggregate calculations, top spending categories, and daily averages.
